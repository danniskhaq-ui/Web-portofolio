<p style="text-align: justify;"><br /></p><p data-path-to-node="2" style="text-align: justify;">Dalam dunia pembuatan website, jika HTML bertugas membuat kerangka dan struktur halaman, maka CSS (<i data-index-in-node="99" data-path-to-node="2">Cascading Style Sheets</i>) adalah elemen yang bertanggung jawab atas estetika visualnya. Tanpa CSS, sebuah halaman web hanya akan tampak seperti dokumen teks polos yang kaku dan kurang menarik. CSS memungkinkan para pengembang untuk mengatur warna, tata letak, gaya tulisan, hingga respon tampilan halaman saat dibuka di berbagai ukuran layar seperti ponsel maupun komputer. Oleh karena itu, menguasai dasar-dasar CSS merupakan langkah wajib bagi siapa saja yang ingin menciptakan situs web yang tidak hanya fungsional, tetapi juga memiliki tampilan yang modern dan responsif.</p><p data-path-to-node="4" style="text-align: justify;"><br /></p><p data-path-to-node="5" style="text-align: justify;">Secara mendasar, CSS bekerja dengan cara memilih elemen HTML tertentu lalu menerapkan aturan gaya padanya. Aturan penulisan CSS terdiri dari tiga komponen utama, yaitu <i data-index-in-node="168" data-path-to-node="5">selector</i> untuk memilih elemen HTML yang ingin diubah, <i data-index-in-node="222" data-path-to-node="5">property</i> untuk menentukan sifat visual yang akan diatur, dan <i data-index-in-node="283" data-path-to-node="5">value</i> untuk menetapkan nilai perubahan tersebut. Sebagai contoh, Anda dapat memilih seluruh elemen paragraf lalu menentukan warna teks menjadi biru dan ukuran huruf sebesar 16 piksel.</p><p data-path-to-node="6" style="text-align: justify;">Dalam penerapannya pada dokumen HTML, terdapat tiga metode penyambungan yang umum digunakan. Metode pertama adalah <i data-index-in-node="115" data-path-to-node="6">Inline CSS</i>, di mana aturan gaya dituliskan langsung di dalam atribut tag HTML bersangkutan. Metode kedua adalah <i data-index-in-node="227" data-path-to-node="6">Internal CSS</i>, yang dituliskan di dalam tag khusus pada bagian kepala dokumen HTML. Metode ketiga yang paling direkomendasikan adalah <i data-index-in-node="360" data-path-to-node="6">External CSS</i>, di mana seluruh aturan gaya disimpan dalam file terpisah berekstensi <code data-index-in-node="443" data-path-to-node="6">.css</code> lalu dihubungkan ke dokumen HTML. Cara terakhir ini menjadi standar utama karena membuat struktur kode tetap rapi dan mudah dikelola.</p><p data-path-to-node="7" style="text-align: justify;">Selain memahami cara penulisan, konsep penting yang wajib dikuasai dalam CSS adalah <i data-index-in-node="84" data-path-to-node="7">Box Model</i>. Konsep ini memandang setiap elemen HTML sebagai sebuah kotak persegi yang memiliki empat lapisan utama. Lapisan tersebut meliputi <i data-index-in-node="225" data-path-to-node="7">content</i> yang berisi data asli seperti teks atau gambar, <i data-index-in-node="281" data-path-to-node="7">padding</i> yang memberikan ruang pembatas di dalam kotak, <i data-index-in-node="336" data-path-to-node="7">border</i> sebagai garis tepi luar, serta <i data-index-in-node="374" data-path-to-node="7">margin</i> yang mengatur jarak antar-elemen kotak di dalam halaman web.</p><p data-path-to-node="9" style="text-align: justify;"><br /></p><p data-path-to-node="10" style="text-align: justify;">Secara keseluruhan, CSS merupakan fondasi utama dalam perancangan antarmuka (<i data-index-in-node="77" data-path-to-node="10">user interface</i>) sebuah situs web. Dengan memahami sintaks dasar, cara penargetan elemen, serta konsep <i data-index-in-node="179" data-path-to-node="10">box model</i>, Anda dapat dengan mudah mengubah tampilan dokumen HTML yang sederhana menjadi sebuah halaman web yang menarik dan nyaman dibaca. Penguasaan CSS yang baik juga akan memudahkan Anda dalam mempelajari kerangka kerja (<i data-index-in-node="404" data-path-to-node="10">framework</i>) modern seperti Tailwind CSS atau Bootstrap di tahap pengembangan selanjutnya.</p>
