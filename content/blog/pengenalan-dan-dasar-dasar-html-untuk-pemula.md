<p><br /></p><p data-path-to-node="2">Memasuki dunia pengembangan web, HTML (<i data-index-in-node="39" data-path-to-node="2">HyperText Markup Language</i>) merupakan materi pertama yang wajib dipelajari oleh setiap calon pengembang (<i data-index-in-node="143" data-path-to-node="2">developer</i>). Sebagai bahasa standar web, HTML bertugas membentuk kerangka utama dan struktur dasar dari setiap situs yang ada di internet. Tanpa adanya struktur HTML, sebuah halaman web tidak akan memiliki kejelasan dalam menampilkan teks, gambar, tautan, maupun media lainnya. Meskipun tergolong sebagai teknologi dasar yang relatif mudah dipelajari, pemahaman yang keliru terhadap sintaks dan fungsi elemen HTML dapat menyebabkan tampilan halaman menjadi tidak beraturan serta sulit dibaca oleh mesin pencari. Oleh karena itu, menguasai konsep-konsep dasar HTML secara benar menjadi fondasi terpenting sebelum melangkah ke tahap pemrograman web yang lebih kompleks.</p><p data-path-to-node="4"><br /></p><p data-path-to-node="5">Komponen paling mendasar dari HTML adalah <b data-index-in-node="42" data-path-to-node="5">tag</b>, yang ditulis di antara tanda kurung siku (seperti <code data-index-in-node="97" data-path-to-node="5">&lt;tag&gt;</code>). Sebagian besar tag HTML bekerja secara berpasangan, terdiri dari tag pembuka dan tag penutup yang ditandai dengan tanda garis miring (seperti <code data-index-in-node="247" data-path-to-node="5">&lt;/tag&gt;</code>). Dokumen HTML standar diawali dengan deklarasi <code data-index-in-node="302" data-path-to-node="5">&lt;!DOCTYPE html&gt;</code>, diikuti oleh tag induk <code data-index-in-node="342" data-path-to-node="5">&lt;html&gt;</code> yang membungkus seluruh area kerja. Di dalamnya, dokumen terbagi menjadi dua bagian utama: <code data-index-in-node="440" data-path-to-node="5">&lt;head&gt;</code> untuk menampung data informasi situs seperti judul (<code data-index-in-node="499" data-path-to-node="5">&lt;title&gt;</code>) dan pustaka eksternal, serta <code data-index-in-node="537" data-path-to-node="5">&lt;body&gt;</code> untuk memuat seluruh konten visual yang dilihat oleh pengguna.</p><p data-path-to-node="6">Di dalam bagian <code data-index-in-node="16" data-path-to-node="6">&lt;body&gt;</code>, terdapat beberapa elemen dasar yang paling sering digunakan untuk menyusun informasi:</p><ul data-path-to-node="7"><li><p data-path-to-node="7,0,0"><b data-index-in-node="0" data-path-to-node="7,0,0">Heading (<code data-index-in-node="9" data-path-to-node="7,0,0">&lt;h1&gt;</code> hingga <code data-index-in-node="21" data-path-to-node="7,0,0">&lt;h6&gt;</code>):</b> Digunakan untuk membuat judul atau subjudul. <code data-index-in-node="73" data-path-to-node="7,0,0">&lt;h1&gt;</code> mewakili tingkatan judul tertinggi dan terpenting, sedangkan <code data-index-in-node="139" data-path-to-node="7,0,0">&lt;h6&gt;</code> merupakan yang terkecil.</p></li><li><p data-path-to-node="7,1,0"><b data-index-in-node="0" data-path-to-node="7,1,0">Paragraf (<code data-index-in-node="10" data-path-to-node="7,1,0">&lt;p&gt;</code>):</b> Berfungsi untuk membungkus blok teks atau narasi utama.</p></li><li><p data-path-to-node="7,2,0"><b data-index-in-node="0" data-path-to-node="7,2,0">Tautan (<code data-index-in-node="8" data-path-to-node="7,2,0">&lt;a href="..."&gt;</code>):</b> Digunakan untuk membuat <i data-index-in-node="49" data-path-to-node="7,2,0">hyperlink</i> yang menghubungkan pengguna ke halaman lain atau situs eksternal.</p></li><li><p data-path-to-node="7,3,0"><b data-index-in-node="0" data-path-to-node="7,3,0">Gambar (<code data-index-in-node="8" data-path-to-node="7,3,0">&lt;img src="..." alt="..."&gt;</code>):</b> Berfungsi untuk menampilkan media visual, di mana atribut <code data-index-in-node="94" data-path-to-node="7,3,0">src</code> menyimpan lokasi gambar dan <code data-index-in-node="126" data-path-to-node="7,3,0">alt</code> memberikan deskripsi alternatif teks.</p></li><li><p data-path-to-node="7,4,0"><b data-index-in-node="0" data-path-to-node="7,4,0">Daftar/List (<code data-index-in-node="13" data-path-to-node="7,4,0">&lt;ul&gt;</code>, <code data-index-in-node="19" data-path-to-node="7,4,0">&lt;ol&gt;</code>, <code data-index-in-node="25" data-path-to-node="7,4,0">&lt;li&gt;</code>):</b> Digunakan untuk menyusun poin-poin informasi, baik yang tidak berurutan (<i data-index-in-node="105" data-path-to-node="7,4,0">unordered list</i>) maupun yang berurutan (<i data-index-in-node="144" data-path-to-node="7,4,0">ordered list</i>).</p></li></ul><p data-path-to-node="9" style="text-align: justify;"><br /></p><p data-path-to-node="10">Secara keseluruhan, pemahaman terhadap sintaks tag, struktur hierarki dokumen, serta fungsi masing-masing elemen HTML merupakan modal utama dalam membangun situs web yang terstruktur dengan baik. Dengan menguasai konsep dasar ini, penyusunan tata letak informasi akan menjadi jauh lebih rapi, teratur, dan mudah dipahami baik oleh pengguna maupun sistem peramban. Penguasaan HTML yang solid juga akan mempermudah proses belajar selanjutnya saat mengintegrasikan CSS untuk mempercantik gaya visual dan JavaScript untuk memberikan fungsi interaktif pada halaman web.</p>
