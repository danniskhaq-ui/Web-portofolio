Tentang Saya

Saya adalah seorang pelajar jurusan Pengembangan Perangkat Lunak dan Gim (PPLG).

Saya memiliki fokus dan ketertarikan mendalam di bidang Web Development. Saya senang membangun halaman web yang fungsional, responsif, dan terstruktur dengan memanfaatkan teknologi database seperti MySQL.

Cerita Saya

Dari "Hello World" Pertama, Hingga Pengembangan Web.

Ketertarikan saya pada PPLG dimulai saat menulis baris kode pertama di kelas 10. Dari yang awalnya bingung melihat syntax, saya belajar bahwa coding adalah tentang memecahkan masalah secara logis. Setiap bug dan error yang saya temui justru mengajarkan saya untuk lebih teliti, tahan banting, dan terus berkembang.

Prinsip Coding

  • Kode Rapi

    Menulis kode yang terstruktur dan mudah dipahami untuk pengembangan jangka panjang.

  • Problem Solving

    Berfokus mencari solusi yang paling efisien untuk setiap masalah dan error yang terjadi.

  • Selalu Adaptif

    Rutin belajar mandiri untuk menguasai tools dan language.
